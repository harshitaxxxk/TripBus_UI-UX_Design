## 🎨 UI/UX Design

TripBus is a bus booking and travel platform designed to provide a simple and user-friendly travel booking experience.

### Design Highlights

* 🚌 Bus ticket booking
* 🗺️ Tourist tour exploration
* 🎫 Booking management
* 🏨 Hotel discovery
* 💬 Help and support
* 🔐 User login interface

### Figma Design
